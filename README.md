# Student Grade Manager

A small terminal-based Python program that stores student marks, calculates an average, assigns a grade, and prints a clear summary.

## How to run

```bash
cd student_grade_manager
python3 grade_manager.py
```

## Features

- Stores student names and marks
- Validates bad input like blank names, negative marks, and numbers above 100
- Calculates each student's average mark
- Assigns grades using:
  - A: 90+
  - B: 75-89
  - C: 60-74
  - D: 50-59
  - F: below 50
- Prints a clear, readable terminal report
